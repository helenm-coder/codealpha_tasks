# CodeAlpha Data Science Internship

## Task: Unemployment Analysis in India

### Objective
Analyze unemployment trends in India using Python and data visualization techniques.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### Project Description
This project analyzes unemployment data across Indian states and union territories. Data cleaning, exploratory data analysis, and visualizations were performed to identify patterns and trends in unemployment rates.

### Outcome
The analysis provided insights into unemployment variations across regions and time periods.
